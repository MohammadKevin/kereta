## 📌 Overview
An intuitive web interface for searching train schedules, selecting carriage seats via an interactive layout, and managing passenger bookings.

---

## ✨ Key Features
- ⚡ **Interactive seat picker with carriage switching**: Interactive seat picker with carriage switching
- ⚡ **Departure and arrival route lookup with real-time filters**: Departure and arrival route lookup with real-time filters
- ⚡ **Admin panel for managing trains, schedules, and ticket pricing**: Admin panel for managing trains, schedules, and ticket pricing

---

## 🛠️ Tech Stack
- **Framework**: Next.js
- **Language**: TypeScript
- **UI**: Radix UI, Tailwind CSS, React Hook Form

## 🚀 Getting Started

### Prerequisites
Make sure you have the required runtimes and tools installed on your machine:
- Node.js (v18+ recommended) / Appropriate runtime
- Git

### Installation & Local Setup
```bash
git clone https://github.com/MohammadKevin/kereta.git
cd kereta
npm install
npm run dev
```
